# GastroCare — Claude Code Bootstrap

Trước khi thực hiện bất kỳ task nào:

1. Đọc `AGENTS.md`.
2. Thực hiện Startup Protocol trong `AGENTS.md`.
3. Lấy branch/task hiện tại từ `docs/PROJECT_STATE.md` → `CURRENT EXECUTION CONTEXT`.
4. Không commit/push khi Owner chưa phê duyệt rõ ràng.

`AGENTS.md` là nguồn chuẩn cho AI working agreement. Không duy trì context riêng trùng lặp trong file này.
